網頁小精靈 v22｜透明動畫＋同步配音

這是作品集更新包，共 11 個網站檔案，保留原來的網站內容。

GitHub 上傳方式
1. 解壓縮這個 ZIP，不要直接把 ZIP 放進網站。
2. portfolio 根目錄：上傳並覆蓋 index.html、companion-lab.html。
3. assets/companion/ 資料夾：上傳本包該資料夾裡的全部 9 個檔案。
   路徑維持 assets/companion/，不要再多加一層 companion。
4. 舊的小精靈圖片可以保留。README-UPDATE-v22.txt 不用上傳。
5. 等 GitHub Pages 部署完成，再開正式網站重新整理。

這次更新
- 首頁與小精靈試玩頁都換成你提供的角色動畫。
- 使用約 1.37 MB 的透明動畫 WebP，並帶入你的 MP3。
- 召喚／點擊角色、選動作時，動畫和配音一起播放。
- 左鍵點角色會開啟選單，按「關閉聲音／開啟聲音」切換靜音。
- 手機同樣點角色開選單。右鍵維持瀏覽器原本功能。
- 靜音後動畫繼續；暫停、收起、切到背景時，配音停止。
- 配音隨 6.1 秒動畫循環；重新開始動作時配音從頭開始，不會疊加。
- 保留自由拖曳、跳舞、暫停與記住靜音偏好。
- 首次進頁面不會強制自動出聲；點擊召喚、角色或動作後啟用。

線上測試
首頁：點召喚小精靈 → 點角色 → 選單關閉聲音 → 動畫應繼續。
試玩頁：companion-lab.html → 點角色播放 → 選單暫停 → 動作和聲音都應停止。
手機：確認角色背景透明，點角色後能看到聲音開關，拖曳不會跑出畫面。
若已記住靜音，先在選單按「開啟聲音」。

檢查紀錄
本機 Chromium 桌面與手機尺寸：透明顯示、點擊聲音、左鍵靜音、暫停與拖曳皆已驗證，無 console error。
已檢查子目錄素材路徑、音訊不疊播、暫停後延遲載入不會冒出聲音、檔案及壓縮包完整性。
