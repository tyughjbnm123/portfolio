使用方式
1. 解壓縮後，把所有 HTML 與 assets 資料夾放進 portfolio GitHub 儲存庫的網站根目錄，取代同名檔案。
2. 維持 HTML 與 assets 的相對位置，再提交至 GitHub；等 GitHub Pages 部署完成。
3. 開啟 ai-tools.html 測試。若仍看到舊版，按 Ctrl+Shift+R 重新整理。
4. tests 是開發測試，不需要上傳；此包已排除。
