上傳方式
1. 先解壓縮 ZIP。解壓後應看到 index.html、多個 HTML 頁面、assets 和 shot-composer 資料夾。
2. 將這些「內容」上傳至現有 portfolio 儲存庫根目錄；不要把 ZIP 本身或最外層解壓資料夾上傳。
3. 同名檔案請覆蓋。保留儲存庫原有 .github、CNAME、README 等設定，不需要先刪除網站。
4. 若使用 GitHub 網頁上傳，檔案較多時分批：先傳根目錄 HTML，再傳 assets，最後傳 shot-composer。
   也可以進入對應資料夾逐批傳入內容，但務必保持相同路徑：
   - assets/companion/：小精靈程式、clips-v24.json、WebP、MP3。
   - assets/：頁面樣式、腳本、圖片及 KKS 影片等素材。
   - shot-composer/：3D 編輯器完整內容，包含 assets、help、poses、LICENSE 與授權聲明。
   不要變成 assets/assets 或 assets/companion/companion。
5. 提交後等 GitHub Pages 部署完成，再重新整理線上作品集。若仍顯示舊版，可用無痕視窗確認。
6. README-upload-v27.txt 是操作說明，manifest 是核對清單，不是網站執行必要檔案。
