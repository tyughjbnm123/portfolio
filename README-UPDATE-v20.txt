網頁小精靈 v20｜自由拖曳版（2026-09-22）

這是本次小精靈的更新包，不是整站備份。

上傳方式
1. 解壓縮，將 index.html、companion-lab.html 上傳到原網站根目錄並覆蓋。
2. 將 assets/companion/ 資料夾合併到原網站的 assets/companion/。
   圖片和 blackhair-mask-v1.png 必須一起上傳，檔名大小寫不要更改。
3. 請合併資料夾，不要刪除其他既有的 assets 檔案。
4. README-UPDATE-v20.txt、GENERATION-v20.md 不必上傳。
5. 原有作品圖片、影片及 3D 編輯器不必重新上傳。

操作
• 首頁右下角按「召喚小精靈」，角色直接浮在網頁上。
• 抓住角色拖動，可移到畫面任意位置；捲動頁面時留在畫面上。
• 點一下角色才展開選單：跳舞、休息、暫停、繼續、收起。
• 拖曳不會誤開選單；點其他地方可以關閉選單。
• 首頁會在同一瀏覽器記住開關、動作及位置。首次造訪預設收起。
• 鍵盤聚焦角色後，方向鍵可移動；Esc 關閉選單，再按一次收起。
• 首頁全程安靜，不播放音效。

探索頁
「我正在探索」保留原有六個分類，在下方加入「網頁小精靈」入口。
companion-lab.html 為完整試玩頁，一開啟就能自由拖曳角色。
可回到舞台調整動作與節奏，再放回網頁；音效須自行開啟。

素材說明
本版為四姿勢 2D 動畫，使用圖像加輪廓遮罩在網頁中去除方形底色。
首頁和試玩頁都需同時保留兩張 PNG，並非僅上傳造型圖就足夠。
CSS／JS 使用相對路徑，可放在 GitHub Pages 的 portfolio 子目錄。
載入後仍看到舊頁面，可用 Ctrl+F5 重新整理。
