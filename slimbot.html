04.07 / SYSTEM AUTOMATION

SlimBot
社群任務自動化

把分散的社群操作，
整理成可追蹤的任務。

面向 Facebook、Instagram 與 Threads 的社群任務管理專案。由 Web 整理任務、內容提示與素材，再交給本機 Runner 串接瀏覽器操作及 AI 服務，將執行狀態與結果帶回管理端。

01 / SOCIAL TASKS

把社群需求，整理成任務

從內容方向、素材，到執行數量。

一次任務包含平台、類型、摘要與執行數量；依任務需求，再填入目標貼文、AI 提示或上傳素材。管理端把等待執行與已執行的任務分開，方便追蹤後續處理。

CONTENT / MATERIALS

內容與素材一起設定

文字提示可指定內容方向、語氣與重點；支援的任務可選擇自備圖片／影片，或提供 AI 繪圖提示。回覆類型再搭配目標貼文網址，讓內容與操作對象一起保存。

FORM / VALIDATION

依平台調整輸入規則

  • Facebook 限時動態：一張圖片，文字可留空，最多 120 字。
  • Instagram 貼文：需提供素材，或啟用 AI 圖片生成。
  • Threads 貼文：自選附件最多 10 個。

以上為程式中的功能與表單規則；各平台的實際執行結果仍需搭配實機測試確認。

03 / WEB + RUNNER

從建立任務，到查看結果

網頁管理與本機操作，各有清楚的入口。

WEB / DASHBOARD

執行狀況總覽

儀表板呈現 Facebook、Instagram 任務統計、環境數量與執行中清單，讓使用者先掌握目前的工作狀態。

WEB / TASKS

任務與素材管理

以平台切換任務列表，分開查看等待中與已執行項目。任務表單依類型顯示文字、網址、AI 圖片及附件欄位。

WEB + RUNNER / PROFILES

帳號與人物設定

管理 Profile 資訊與人物設定文字，並在領取任務時帶入對應情境，作為內容生成與執行時的參考。

WEB / ROLES

管理員與使用者

介面區分管理員與一般使用者，提供帳號、系統設定與不同管理入口，將系統維護和日常操作分工。

RUNNER / CONNECTION

連線與模型設定

在本機設定 Web、AdsPower、文字與圖片模型，以及瀏覽器數量。儲存設定後，由使用者手動啟動監控。

RUNNER / MONITORING

任務監控與錯誤

透過任務卡片查看執行狀態、保留停止操作，並以獨立頁籤整理最近的本機錯誤與任務名稱。

04 / EXECUTION DESIGN

執行之外，還要處理中斷與追查

展開查看程式中的處理機制。

01 / DISPATCH依容量領取，分開記錄每次執行＋

領取 API 接收可用瀏覽器槽位數，檢查任務剩餘數量並選擇可用 Profile。程式透過資料庫交易與資料列鎖定更新任務，同時建立個別執行紀錄，作為後續回報的依據。

tasks：任務與數量　／　task_runs：每次執行

02 / RECOVERY用心跳辨識中斷，回收逾時狀態＋

執行中的工作回報 Heartbeat。程式在檢查時，會將預設超過 120 秒未更新的執行紀錄標為取消；若該任務沒有其他執行中的紀錄，而且尚未達到處理數量，便回到等待佇列。這項設計用來處理 Runner 中斷後仍停留在「執行中」的情況。

heartbeat_at：最後回報　／　queued：重新等待領取

03 / TRACEABILITY將內容、流程與結果分開保存＋

任務的提示、附件與執行情境放在獨立資料結構，操作步驟則以 JSON 流程定義管理，並有讀取與儲存 API。完成回報保存結果、錯誤訊息與截圖路徑欄位，同時累計成功與失敗次數，讓問題可以追到特定執行紀錄。

task_payloads：任務內容　／　task_flow_versions：流程定義

上述機制已有程式實作；跨使用者的任務權限、重複回報及中斷恢復，仍需整合測試確認。

05 / DEPLOYMENT + HANDOFF

把環境建置，也整理成可交接的流程

從資料庫、Web 服務，到登入驗證。

  1. 01

    建立服務與資料庫

    部署文件記錄 Zeabur 專案、MySQL 服務與資料表匯入，涵蓋任務、執行紀錄、流程及帳號資料結構。

  2. 02

    配置 Web 環境

    部署 PHP 專案，透過環境變數設定資料庫連線與網站位置，再完成網域與 DNS 綁定。

  3. 03

    串接登入驗證

    設定 Cloudflare Turnstile。Web 登入程式會檢查驗證結果與帳號密碼，再建立登入狀態。

  4. 04

    交接操作與維護

    以部署說明、設定修改文件及操作錄影保留建置步驟；文件也交代環境變數更新後重啟，以及資料庫管理工具用畢後停用。
