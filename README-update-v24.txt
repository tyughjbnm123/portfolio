網頁小精靈 v24｜2026-09-22

本次更新
1. 首頁與小精靈介紹頁的閒置打哈欠改為 10 秒。
2. 刪除六張卡片下方「選單只留三個控制」的重複說明區。
3. 六張卡片皆可點擊，也支援鍵盤 Enter／空白鍵。
4. 點卡片直接播放對應動作；角色收起時會直接召喚播放。
5. 只有待機動作循環播放。手動點「安靜待機」時配音一次；自動回到待機保持安靜。
6. 點「下次見」播完後收起角色。
7. 其他五個動作與所有配音維持單次播放；手動打哈欠後不會緊接著再自動打一次。

上傳方式
這是現有作品集的更新包，保留網站其他原有檔案。
解壓縮後，把 index.html、companion-lab.html 上傳至 GitHub portfolio 儲存庫根目錄，覆蓋同名檔案。
接著到 assets/companion，上傳解壓縮同一路徑內的全部 25 個檔案。
不要在 assets/companion 裡再建立另一層 assets/companion。
確認 GitHub Pages 部署完成後重新整理。
此包包含所需的六組動畫與配音，可直接取代 v23 更新包使用；不必刪除舊檔。

閒置條件
角色開啟、處於待機、選單關閉，並正在瀏覽這個分頁時才會觸發。
點擊、按鍵、拖曳與捲動都會重新計時。單純移動滑鼠不重設。
打哈欠一次之後，直到再次操作才重新計時；不會連續自動重播。
若系統偏好減少動態，停用自動打哈欠，仍可手動點卡片播放。
