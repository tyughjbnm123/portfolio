網頁小精靈 v23 更新包｜2026-09-22

這是現有作品集的更新包，保留原本網站其他檔案。

GitHub 上傳方法
1. 解壓縮 ZIP。
2. 在 portfolio 儲存庫根目錄，上傳並覆蓋 index.html、companion-lab.html。
3. 打開 assets/companion 資料夾，上傳解壓縮後同一路徑內的全部 25 個檔案。
   請上傳資料夾內的檔案，避免多一層 assets/companion/assets/companion。
4. Commit changes，等待 GitHub Pages 部署完成，再重新整理網站。
   不需要把原始 MP4 上傳，也不需要刪除舊版素材。

這次內容
- 待機、歡迎、拖曳、跳舞、打哈欠、再見，共六個透明 WebP。
- 每個 WebP 480×452、20 fps、6.15 秒，檔案本身只播放一次。
- 配音沿用你提供的六個 MP3，壓縮為 128 kb/s。
- 待機保持安靜；待機 MP3 有保留在素材包內，網站不自動播放。
- 召喚播放歡迎；拖曳超過 8px 觸發一次，放下後把這次動作與配音播完。
- 左鍵或手機輕點角色，開啟「跳舞、聲音、收起」三個控制。
- 跳舞只播一次；各動作結束後進入一次待機動畫，最後停在靜態畫面。
- 沒操作约 45 秒觸發一次打哈欠，再次操作前不會重複觸發。
- 收起先播放再見一次，再縮回召喚按鈕。
- 聲音圖示 15px，點擊區域至少 36px；記住靜音設定。
- 中途取消靜音接續目前動作的聲音位置，不從頭再播。
- 切到其他分頁會停下聲音與動作，回來不會重播剛才那段。
- 位置可拖曳並記住；首頁與小精靈介紹頁使用同一套播放器。

素材名稱
idle = 待機模式 / welcome = 歡迎訊息 / drag = 拖曳
dance = 跳舞 / yawn = 打哈欠 / bye = 再見
*-still-v23.webp 是各動作的最後一張靜態圖。
